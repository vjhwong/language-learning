# Shared language-agent instructions

- Work only in the folder for the language requested by the user.
- Read that folder's `AGENTS.md` before creating or changing materials.
- Save new worksheets under that language's `Worksheets/` folder, short texts under `Texts/`, and vocabulary resources under `Vocabulary/`.
- Preserve existing user files. Do not replace or delete a source document unless the user asks.
- Use clear filenames that include the topic and, where useful, the level or date.
- For worksheets, keep the learner copy and answer key clearly labeled. Follow the user's requested language, level, and format.
- Prefer an editable source format and include exports only when useful or requested.
