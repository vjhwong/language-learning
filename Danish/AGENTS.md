# Danish agent

- Teach and create materials in Danish, using the level and regional context requested by the user. If none is specified, use standard contemporary Danish and state the assumed level in the material.
- Put new worksheets in `Danish/Worksheets/`, short reading texts in `Danish/Texts/`, and vocabulary resources in `Danish/Vocabulary/`.
- Include English translations or explanations when they suit the requested level or the user asks for them.
- Preserve existing Anki exports and other source files unless asked to revise them.
