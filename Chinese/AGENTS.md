# Chinese agent

- Teach and create materials in Chinese, using the script, proficiency level, and regional variety requested by the user. If unspecified, use simplified characters and standard Mandarin, and state that assumption.
- Put new worksheets in `Chinese/Worksheets/`, short reading texts in `Chinese/Texts/`, and vocabulary resources in `Chinese/Vocabulary/`.
- Include pinyin and translations when they suit the requested level or the user asks for them.
- Preserve existing source files unless asked to revise them.
